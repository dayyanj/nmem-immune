# Configuration — nmem-immune

nmem-immune is the memory **immune system**: five layers (skeptic → quarantine → drift →
antidote → immunity) that screen incoming/aging memories for contradictions, poison, and
staleness. Every runtime knob is an environment variable; this document is the complete,
authoritative reference plus a set of recipes for common setups.

## How configuration works

All settings live on one `pydantic-settings` model, `Settings`, in
[src/nmem_immune/config.py](../src/nmem_immune/config.py), exposed as a singleton:

```python
from nmem_immune import config
if config.settings.skeptic_enabled:
    ...
```

- **One canonical name per flag.** The env var is always `NMEM_IMMUNE_` + the field name
  upper-cased — e.g. the field `skeptic_scan_limit` ⇄ `NMEM_IMMUNE_SKEPTIC_SCAN_LIMIT`.
  There are **no aliases**: rename the field and the env var moves with it.
- **Precedence:** process environment variables override the built-in defaults. Nothing else
  is read (there's no `.env` file loader wired in); `extra="ignore"` means unknown
  `NMEM_IMMUNE_*` vars are silently ignored, so a typo'd flag has no effect.
- **Everything is optional.** Every field has a default, so immune runs with no env set at all.
- **Booleans** accept `1/0`, `true/false`, `yes/no`, `on/off` (case-insensitive). An
  *invalid* value (e.g. `NMEM_IMMUNE_SKEPTIC_ENABLED=maybe`) raises at startup rather than
  silently defaulting — prefer `1`/`0`.
- **Two knobs silently clamp** to protect the scan cost, exactly as before the config
  refactor: `SKEPTIC_SCAN_LIMIT` is capped at **200** and `DRIFT_SAMPLE_SIZE` at **100**
  (set a higher value and you get the cap, no error).
- **Three knobs are floored at 1** (`ge=1`): the `QUARANTINE_*` day/source counts reject `0`
  or negatives with a validation error.
- **⚠ UNWIRED flags** are declared and documented but not yet read anywhere in-repo (kept so
  the surface is complete and self-documenting). Setting them has no effect today; they're
  marked in the reference table below.
- **Not env-configurable:** the trust weightings `GROUNDING_TRUST` and `SOURCE_TRUST` are
  module-level constants in `config.py` (edit the code to change them), not runtime flags.

To dump every resolved value for a running configuration:

```python
python -c "from nmem_immune import config; import json; print(json.dumps(config.settings.model_dump(), indent=2))"
```

## Recipes

### Run with defaults (recommended starting point)

Set nothing. The skeptic layer is **ON** by default and screens every incoming memory;
quarantine/drift/antidote/immunity apply their default thresholds. This is the intended
production posture — tune only once you see a specific false-positive/negative rate.

### Point immune at your database

```bash
export NMEM_IMMUNE_DB_DSN="postgresql://user:pass@host:5432/nmem"
```

> ⚠ `NMEM_IMMUNE_DB_DSN` is currently **UNWIRED** — no code path reads it yet. Confirm how your
> deployment actually supplies immune's DSN (it may inherit the host's nmem connection) before
> relying on this flag.

### Make the skeptic stricter (catch more, risk more false positives)

Lower the thresholds so more overlaps/divergences trip the screen:

```bash
export NMEM_IMMUNE_SKEPTIC_TEXT_OVERLAP_THRESHOLD=0.5     # was 0.7 — flag looser duplicates
export NMEM_IMMUNE_SKEPTIC_VECTOR_DIVERGENCE_THRESHOLD=0.3 # was 0.4 — flag smaller conflicts
export NMEM_IMMUNE_SKEPTIC_POISON_PATTERN_THRESHOLD=0.5    # was 0.6 — match poison earlier
```

To go the other way (fewer, higher-confidence flags), raise the same values toward `1.0`.

### Turn the skeptic off entirely

```bash
export NMEM_IMMUNE_SKEPTIC_ENABLED=0
```

Layers 2–5 still apply; only the incoming-contradiction/poison screen is disabled.

### Scale scan throughput

The skeptic and drift passes bound how much they examine per cycle. Raise them for denser
screening on a beefier DB (remember the silent caps):

```bash
export NMEM_IMMUNE_SKEPTIC_SCAN_LIMIT=200   # max useful value (capped at 200)
export NMEM_IMMUNE_DRIFT_SAMPLE_SIZE=100    # max useful value (capped at 100)
```

### Tune quarantine holding policy

How long suspect memories age before re-evaluation, and when they expire:

```bash
export NMEM_IMMUNE_QUARANTINE_AGING_DAYS=3    # re-evaluate sooner (min 1)
export NMEM_IMMUNE_QUARANTINE_EXPIRY_DAYS=30  # expire unresolved items sooner (min 1)
```

### Tune retirement of low-confidence memories

```bash
export NMEM_IMMUNE_IMMUNITY_MIN_CONFIDENCE=0.15       # retire below this confidence
export NMEM_IMMUNE_IMMUNITY_RETIREMENT_THRESHOLD=0.15
```

### Layer 1: Skeptic

| Env var | Default | Type | Purpose |
|---|---|---|---|
| `NMEM_IMMUNE_SKEPTIC_ENABLED` | `True` | bool | Enable the skeptic layer (contradiction/poison screen). Default ON. |

| `NMEM_IMMUNE_SKEPTIC_TRUST_DELTA_THRESHOLD` | `0.3` | float | Trust level below which a source disagreement is flagged suspicious. |
| `NMEM_IMMUNE_SKEPTIC_POISON_PATTERN_THRESHOLD` | `0.6` | float | Immunity score above which a memory matches a known poison pattern. |
| `NMEM_IMMUNE_SKEPTIC_SCAN_LIMIT` | `20` | int | Max memories scanned per skeptic pass (silently clamped to ≤200). |
